# Usage Instructions for ../lsmvq_zipformer.sh

This document provides detailed instructions for running the lsmvq_zipformer.sh script, which performs knowledge distillation using the Zipformer model. The script is executed stage by stage, and the official model file pretrained.pt must be renamed and placed in the exp_dir directory. Refer to RESULTS.md in the same directory as the script for the source of the official model file.

## Prerequisites
- Rename the official pretrained.pt model file and place it in the exp_dir directory.
- Ensure the required dependencies and environment are set up as per the project requirements.
- The script assumes the presence of variables like embedding_layer, num_codebook, exp_dir, and use_extracted_codebook. Define these appropriately before running the script.
- Pre-generated fbank feature directory `./data/fbank` (generated by prepare.sh) is required, the script will exit with error if this directory does not exist.

## Default Config Variables
stage=0
stop_stage=0
export CUDA_VISIBLE_DEVICES=0
embedding_layers="1,7"
num_codebooks="16,16"
exp_dir=./QUAD/exp

## Stage-by-Stage Execution
The script is divided into multiple stages, each performing a specific task in the knowledge distillation process. Below are the details for each stage.

### Stage 1: Extract Codebook Index
**Trigger**: [ $stage -le 1 ] && [ $stop_stage -ge 1 ]
- Extract vector quantization codebook index from three official Zipformer teacher models (zipformer_l_56, zipformer_m_55, zipformer_s_55).
- Extract index for the two configured embedding layers with matching number of codebooks for each teacher model separately.
- All extracted codebook index files are saved to the exp_dir directory.

### Stage 2: Aggregate Multi-layer Codebook Index
**Trigger**: [ $stage -le 2 ] && [ $stop_stage -ge 2 ]
- Aggregate and combine the single-layer codebook index files generated in Stage 1.
- Combine multi-layer index for single teacher models first, then aggregate index across all teacher models.
- Combined index files are saved in exp_dir with combined prefix.

### Stage 3: Train Student Model
**Trigger**: [ $stage -le 3 ] && [ $stop_stage -ge 3 ]
- Perform the core knowledge distillation training for the lightweight Zipformer student model, using aggregated codebook index as supervision signals.
- Training process includes two phases: 50 epochs training with distillation enabled, 20 epochs fine-tuning with distillation disabled and early stop activated.
- All model checkpoints and training logs are saved to exp_dir/student.

### Stage 4: Decode & Evaluate Student Model
**Trigger**: [ $stage -le 4 ] && [ $stop_stage -ge 4 ]
- Evaluate the performance of the trained student model with greedy search decoding method, output the Word Error Rate (WER) as the core metric.
- All evaluation logs and results are saved to the student model's experiment directory under exp_dir.

## Run Command Examples
```bash
./lsmvq_zipformer.sh  --stage 1  --stop_stage 1
```

## Important Notes
1. All experimental outputs including intermediate files, model checkpoints and evaluation results are stored in exp_dir.
2. The official pretrained.pt model file must be correctly placed in exp_dir before running the script.
3. All dependent Python scripts are located in ./QUAD/ directory and called automatically by the shell script.
4. The script only supports GPU execution, ensure the specified CUDA_VISIBLE_DEVICES is valid and available.
